# Retained assets

All files in `Characters/` are retained, including unused characters, all supplied formats, and their textures. `Zombie_Atlas.png` and the original `License.txt` are also retained.

Used non-character assets live in `public/assets/models/`. Their duplicate source models and textures have been removed from this folder. Each used asset's original licence remains here and alongside its served assets.
